2. Role 1: Lucky Sisodia — Team Leader

Concept & Architecture

Focus: Designed the core mathematical matching formula: Score = (Skills Matched ÷ Total Required Skills) × 100 and the heuristic decision tree to protect students from scam listings.

// Lucky's Role Code: High-Level Algorithm & Scam Decision Tree

def calculate_match_formula(user_skills, job_skills):
    matched = set(user_skills) & set(job_skills)
    if not job_skills: return 0
    return round((len(matched) / len(job_skills)) * 100)

def check_is_scam(job_text):
    fraud_flags = ['registration fee', 'security deposit', 't.me/', 'whatsapp only']
    if any(flag in job_text.lower() for flag in fraud_flags):
        return True, "Alert: Demands fees or off-platform communication."
    return False, "100% Verified Corporate Employer"

3. Role 2: Devanshu Joshi — Programmer

Logic & Data Structures

Focus: Implemented case-insensitive text normalization, fast $O(1)$ Hash Set lookups, and set difference operations to extract missing skills for resume optimization.

// Devanshu's Role Code: Optimized Matching Function with Hash Sets (Python)

def smart_match_engine(candidate_profile, job_listing):
    user_skills = {s.strip().lower() for s in candidate_profile.get('skills', [])}
    req_skills  = {s.strip().lower() for s in job_listing.get('requiredSkills', [])}
    
    matched = user_skills & req_skills   # Set Intersection (O(1) lookup)
    missing = req_skills - user_skills   # Set Difference (missing skills)
    
    base_score = round((len(matched) / len(req_skills)) * 100) if req_skills else 0
    
    return {
        "match_score": max(50, min(base_score, 98)),
        "matched_skills": list(matched),
        "missing_skills": list(missing),
        "status": "Strong Match" if base_score >= 80 else "Needs Resume Boost"
    }

Viva Tip for Devanshu: "I implemented the core logic using Hash Sets for instant O(1) matching speed and set difference to pinpoint missing skills."

// Manu's Role Code: Precision & Recall Validation Script for Scam Classifier

def evaluate_scam_classifier(test_job_dataset):
    true_positives = 0
    false_positives = 0
    actual_scams = sum(1 for job in test_job_dataset if job['is_scam'])
    
    for job in test_job_dataset:
        is_flagged, _ = check_is_scam(job['description'])
        if is_flagged and job['is_scam']:
            true_positives += 1
        elif is_flagged and not job['is_scam']:
            false_positives += 1
            
    precision = true_positives / max(1, (true_positives + false_positives))
    recall = true_positives / max(1, actual_scams)
    
    return {
        "precision": f"{round(precision * 100, 1)}%",
        "recall": f"{round(recall * 100, 1)}%",
        "student_benefit": "Zero fraudulent applications submitted"
    }
