## 📌 Overview
**TalentAI** is an intelligent, mobile-first career acceleration platform tailored for students, fresh graduates, and tech job seekers. It features real-time live tech job feeds, dynamic **AI Skill Compatibility Scores (0–100%)**, an interactive **Kanban Application Pipeline Tracker**, and an **AI Resume Weakness Optimizer**.

## ✨ Key Features

- 🔴 **Real-Time Live Job Feed**: Streams live software engineering, AI/ML, and tech jobs directly from verified APIs with direct official apply links.
- 🏢 **Dynamic Vector Brand Avatars**: Automatic high-definition branded company logos and SVG vector avatars.
- 🪄 **AI Resume Weakness Optimizer**:
  - Audits candidate resumes for missing high-demand industry skills (Docker, AWS, TypeScript).
  - One-click enhancement that dynamically recalculates and boosts candidate job match scores to 95%+.
- 📂 **Multi-Format Document Upload**: Complete support for PDF, Word (`.doc`, `.docx`), RTF, and text files with file size and format inspection.
- 📊 **Interactive Application Tracker**: Kanban lifecycle tracking (`Applied` ➜ `Interview` ➜ `Offer` ➜ `Rejected`) with celebration animations.
- ☁️ **Supabase Cloud Backend**: Production-ready schema with Row-Level Security (RLS) for multi-user authentication and bookmarking.
- 📱 **Mobile PWA & Android Ready**: Responsive mobile-shell layout, bidirectional momentum scrolling, and standalone PWA installation.

## 💻 Local Setup & Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/talentai-job-finder.git
   cd talentai-job-finder
   ```

2. **Run locally**:
   ```bash
   node server.js
   ```

3. **Open in browser**:
   Navigate to `http://localhost:3000`

---

## 🗄️ Database Setup (Supabase)

1. Create a free project on [Supabase](https://supabase.com).
2. Open the **SQL Editor** in your Supabase dashboard.
3. Copy and run the code from `supabase_schema.sql` to generate all tables and security policies.
